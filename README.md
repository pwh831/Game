# BlockCraft

브라우저에서 바로 실행되는 마인크래프트 스타일 복셀 게임입니다. 설치할 것 없이 `index.html`을 브라우저로 열면 됩니다.
(Three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 기능
- 무한 지형 자동 생성: 평지, 언덕, 설산, 바다, 모래사장, 동굴, 나무
- 서바이벌 모드: 체력 10칸, 낙하 피해, 자연 회복, 사망과 부활(인벤토리 유지)
- 크리에이티브 모드: 모든 아이템 무한, 즉시 파괴, 비행, 몹이 공격하지 않음
- 채굴: 블록마다 캐는 시간이 다르고, 알맞은 도구가 있으면 빨라짐. 돌 종류는 곡괭이가 있어야 얻을 수 있음
- 광물: 석탄(나무 곡괭이 이상), 철(돌 곡괭이 이상), 금·다이아몬드(철 곡괭이 이상). 깊이 내려갈수록 귀한 광물
- 화로: 조약돌 8개로 제작. 철·금 광석 → 주괴, 모래 → 유리, 조약돌 → 돌, 돼지고기 → 구운 돼지고기, 나무 → 석탄. 연료는 석탄·나무·판자·막대기를 자동으로 사용
- 도구 4단계: 나무 → 돌 → 철 → 다이아몬드. 철·금·다이아몬드 블록(주괴 9개)
- 인벤토리 36칸(핫바 9칸 포함), 아이템 집기/나누기/버리기
- 제작: 판자, 막대기, 작업대, 화로, 곡괭이·검·도끼·삽, 벽돌, 광물 블록 (작업대 필요한 조합 표시)
- 도구 내구도
- 몹: 돼지(낮, 도망감, 돼지고기를 떨어뜨림), 좀비(밤, 플레이어를 쫓아와 공격, 낮에는 햇빛에 탐)
- 음식: 사과(나뭇잎에서 가끔), 돼지고기, 구운 돼지고기, 썩은 살점 — 우클릭으로 먹으면 체력 회복
- 빛: 하늘빛과 블록빛을 칸마다 퍼뜨리는 조명. 동굴과 지붕 아래는 어둡고, 밤에는 하늘빛이 약해짐
- 횃불: 석탄 1 + 막대기 1 → 4개. 바닥에 세우거나 벽에 붙이고, 받침 블록이 없어지면 떨어짐. 주변을 따뜻한 빛으로 밝힘
- 어두운 곳(동굴)에서는 낮에도 좀비가 생기고, 횃불 근처에는 생기지 않음
- 소리: 캐기·부수기·설치(재질별), 발소리, 착지, 물, 몹 울음, 타격, 피격, 먹기, 줍기, 제작, 화로 — Web Audio로 합성, 메뉴에서 크기 조절
- 앰비언트 오클루전 음영, 낮/밤 순환, 해와 달, 구름, 수중 효과
- 자동 저장(localStorage)
- 조작: 키보드+마우스, 아이패드 키보드+트랙패드, 터치(가상 스틱과 버튼)

## 조작법
| 키 | 동작 |
|---|---|
| W A S D | 이동 (한글 입력 상태에서도 동작) |
| 마우스 / 트랙패드 | 시점 회전 (마우스 잠금이 안 되면 두 손가락 스와이프) |
| 방향키 | 시점 회전 |
| Space | 점프 / 수영 / 비행 상승 |
| Shift | 달리기 / 비행 하강 |
| 좌클릭 (누르고 있기) | 블록 캐기 / 몹 공격 |
| 우클릭 · 두 손가락 클릭 · Ctrl/⌥+클릭 · R | 블록 설치 / 음식 먹기 / 작업대·화로 열기 |
| E | 인벤토리와 제작 |
| 1-9, Tab, [ ] | 아이템 고르기 (마우스 잠금 중에는 휠도 가능) |
| Q | 들고 있는 아이템 하나 버리기 (Ctrl+Q: 한 묶음) |
| F | 비행 (크리에이티브) |
| 휠클릭 | 보고 있는 블록 선택 |
| F3 | 디버그 정보 |
| Esc | 일시정지 |

### 아이패드
- 하드웨어 키보드의 WASD가 한글 입력 상태(ㅈㅁㄴㅇ)에서도 동작합니다.
- 트랙패드: 화면을 클릭하면 마우스 잠금을 시도합니다. 잠금이 안 되는 환경에서는 두 손가락으로 쓸어서 시점을 돌리고, 커서는 움직여도 시점에 영향을 주지 않습니다. 메뉴에서 "커서 이동" 방식과 감도, 스와이프 방향을 바꿀 수 있습니다.
- 우클릭: 두 손가락 클릭, Ctrl이나 ⌥를 누른 채 클릭, 또는 R 키.
- 화면을 손가락으로 터치하면 터치 조작 버튼이 나타나고, 키보드를 누르면 사라집니다.
