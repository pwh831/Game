# BlockCraft

브라우저에서 바로 실행되는 마인크래프트 스타일 복셀 게임입니다. 설치할 것 없이 `index.html`을 브라우저로 열면 됩니다.
(Three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 기능
- 무한 지형 자동 생성: 언덕, 설산, 바다, 모래사장, 동굴
- 바이옴: 평원(풀·꽃), 숲(참나무·자작나무 빽빽), 사막(모래·사암·선인장), 설원(눈·얼음·가문비나무)
- 서바이벌 모드: 체력 10칸, 배고픔 10칸, 낙하 피해, 사망과 부활(인벤토리 유지)
- 배고픔: 걷기·달리기·점프·싸움·채굴로 줄어듦. 배고픔 9칸 이상이면 체력 회복, 0이면 체력이 반 칸까지 깎임, 3칸 이하면 달리기 불가
- 농사: 괭이로 잔디·흙을 갈아 경작지를 만들고 밀 씨앗(풀을 부수면 가끔 나옴)을 심으면 4단계로 자람. 근처에 물이 있으면 더 빨리 자람. 다 자란 밀 3개 → 빵
- 활과 화살: 활(막대기 3 + 양털 3), 화살 4개(막대기 1 + 뼈 1). 우클릭을 누르고 있으면 당겨지고(화면 확대) 놓으면 발사. 박힌 화살은 다시 주울 수 있음. 스켈레톤이 화살을 떨어뜨림
- 건축 블록: 판자·조약돌·돌 반블록, 판자·조약돌 계단, 울타리(뛰어넘을 수 없음), 나무 문(우클릭으로 열고 닫기), 돌 벽돌, 사암, 자작나무
- 반블록과 계단은 점프 없이 걸어서 올라감
- 보트: 판자 5개. 물 위에 놓고 우클릭으로 타서 W/S로 이동, 시점으로 방향 전환, Shift로 내림. 세 번 치면 아이템으로 돌아옴
- 마을: 평원과 사막에 생김. 우물, 집(문·창문·침대·횃불), 밭, 보물 상자가 있고 주민이 돌아다님
- 주민 거래: 주민을 우클릭하면 거래 창. 밀·석탄·가죽 등을 팔아 에메랄드를 모으고, 에메랄드로 빵·도구·갑옷·다이아몬드를 삼
- 크리에이티브 모드: 모든 아이템 무한, 즉시 파괴, 비행, 몹이 공격하지 않음
- 채굴: 블록마다 캐는 시간이 다르고, 알맞은 도구가 있으면 빨라짐. 돌 종류는 곡괭이가 있어야 얻을 수 있음
- 광물: 석탄(나무 곡괭이 이상), 철(돌 곡괭이 이상), 금·다이아몬드(철 곡괭이 이상). 깊이 내려갈수록 귀한 광물
- 화로: 조약돌 8개로 제작. 철·금 광석 → 주괴, 모래 → 유리, 조약돌 → 돌, 돼지고기 → 구운 돼지고기, 나무 → 석탄. 연료는 석탄·나무·판자·막대기를 자동으로 사용
- 도구 4단계: 나무 → 돌 → 철 → 다이아몬드. 철·금·다이아몬드 블록(주괴 9개)
- 인벤토리 36칸(핫바 9칸 포함), 아이템 집기/나누기/버리기
- 제작: 판자, 막대기, 작업대, 화로, 곡괭이·검·도끼·삽, 벽돌, 광물 블록 (작업대 필요한 조합 표시)
- 도구 내구도
- 몹: 돼지·소·양(도망감, 고기·가죽·양털), 좀비(근접), 스켈레톤(거리를 두고 화살), 크리퍼(다가와서 1.5초 뒤 폭발, 블록도 부숨)
- 음식: 사과, 돼지고기·소고기·양고기(화로에서 구우면 회복량 증가), 썩은 살점 — 우클릭으로 먹으면 체력 회복
- 상자: 판자 8개. 27칸 보관, Shift+클릭으로 빠르게 옮기기, 부수면 내용물이 쏟아짐
- 침대: 양털 3 + 판자 3. 밤에 우클릭하면 아침이 되고, 부활 위치가 침대로 바뀜 (근처에 몬스터가 있으면 못 잠)
- 갑옷: 가죽·철·다이아몬드 투구/흉갑/레깅스/부츠. 방어 1점당 피해 4% 감소(최대 80%), 맞을 때마다 닳음. 우클릭이나 Shift+클릭으로 입기
- TNT: 화약 5 + 모래 4. 우클릭으로 불붙이면 3초 뒤 폭발, 근처 TNT도 연쇄 폭발
- 빛: 하늘빛과 블록빛을 칸마다 퍼뜨리는 조명. 동굴과 지붕 아래는 어둡고, 밤에는 하늘빛이 약해짐
- 횃불: 석탄 1 + 막대기 1 → 4개. 바닥에 세우거나 벽에 붙이고, 받침 블록이 없어지면 떨어짐. 주변을 따뜻한 빛으로 밝힘
- 어두운 곳(동굴)에서는 낮에도 좀비가 생기고, 횃불 근처에는 생기지 않음
- 소리: 캐기·부수기·설치(재질별), 발소리, 착지, 물, 몹 울음, 타격, 피격, 먹기, 줍기, 제작, 화로 — Web Audio로 합성, 메뉴에서 크기 조절
- 앰비언트 오클루전 음영, 낮/밤 순환, 해와 달, 구름, 수중 효과
- 자동 저장(localStorage)
- 조작: 키보드+마우스, 아이패드 키보드+트랙패드, 터치(가상 스틱과 버튼)

## 네더와 엔드
- 용암: 깊은 동굴에 있음. 들어가면 큰 피해와 함께 불이 붙음(물에 들어가면 꺼짐). 빛을 냄
- 양동이(철 3): 물·용암을 뜨고 붓기. 용암에 물을 부으면 흑요석(다이아몬드 곡괭이로만 캘 수 있음)
- 자갈(부수면 가끔 부싯돌) → 부싯돌과 부시(철 1 + 부싯돌 1)
- 네더 차원문: 흑요석 틀(안쪽 2×3 이상)에 부싯돌과 부시를 쓰면 열림. 안에 2.5초 서 있으면 이동. 네더의 1칸 = 지상 8칸. 도착지에 차원문이 없으면 새로 만듦
- 네더: 용암 바다와 거대한 동굴, 네더랙, 영혼 모래(느려짐), 발광석, 석영 광석. 물이 증발하고 침대가 폭발함
- 네더 요새: 네더 벽돌 다리가 십자로 뻗어 있고 가운데 방에 보물 상자 2개. 블레이즈가 많음
- 네더 몹: 가스트(폭발하는 불덩이), 블레이즈(불덩이 3연발, 블레이즈 막대), 좀비 피글린(중립, 하나를 때리면 무리가 공격)
- 엔더맨: 밤의 지상과 엔드에 나옴. 중립이지만 눈을 마주치거나 때리면 공격. 맞으면 순간이동. 엔더 진주를 떨어뜨림
- 엔더 진주: 던지면 떨어진 곳으로 순간이동(약간 아픔)
- 엔더의 눈(엔더 진주 + 블레이즈 가루): 던지면 가장 가까운 엔드 요새 쪽으로 날아감. 월드마다 요새 3곳(스폰에서 640~960칸)
- 엔드 요새: 지하 방의 차원문 틀 12개에 엔더의 눈을 모두 넣으면 엔드 차원문이 열림
- 엔드: 공허 위의 섬, 흑요석 기둥 8개와 엔드 수정, 엔더 드래곤(체력 200, 돌진 공격). 수정이 남아 있으면 드래곤이 회복하므로 활로 먼저 부수기. 떨어지면 공허 피해
- 드래곤을 물리치면 섬 가운데 귀환 차원문과 드래곤 알이 생김

## 경험치와 마법 부여
- 몹을 잡거나 석탄·다이아몬드·석영을 캐거나 화로에서 구우면 경험치 구슬이 나옴. 핫바 위 초록 막대와 숫자가 레벨
- 죽으면 레벨을 잃고 일부가 구슬로 떨어짐
- 마법 부여대(다이아몬드 2 + 흑요석 4 + 가죽 3): 도구·무기·갑옷·활을 넣으면 선택지 3개(필요 레벨 5/15/30, 1/2/3레벨 소모)
- 마법: 날카로움(공격력), 효율(캐는 속도), 행운(광석 추가), 내구성(덜 닳음), 보호(피해 감소), 가벼운 착지(부츠, 낙하 피해 감소), 힘(활 피해), 무한(화살이 줄지 않음)
- 마법이 걸린 아이템은 칸에서 보라색으로 빛나고, 고르면 이름 옆에 마법이 표시됨

## 레드스톤
- 레드스톤 광석(높이 16 아래, 철 곡괭이 이상)을 캐면 레드스톤 가루 4~5개
- 가루는 단단한 블록 위에 깔고, 옆·한 칸 위아래로 이어짐. 신호는 15칸까지 가고 켜지면 밝은 빨강
- 신호원: 레버(막대기 + 조약돌, 우클릭으로 켜고 끔), 버튼(돌, 1초), 압력판(돌 2, 플레이어나 몹이 밟으면), 레드스톤 횃불(가루 + 막대기), 레드스톤 블록(가루 9)
- 장치: 레드스톤 램프(가루 4 + 발광석, 켜지면 밝기 15), 문(신호가 들어오면 열림), TNT(신호가 들어오면 점화)
- 레드스톤 횃불은 받침 블록에 신호가 들어오면 꺼짐 → NOT 게이트, 시계 회로를 만들 수 있음
- 피스톤(판자 3 + 조약돌 4 + 철 1 + 레드스톤 1, 작업대): 신호를 받으면 앞의 블록을 최대 12칸까지 밀고, 플레이어·몹도 밀어냄. 앞면이 설치하는 사람 쪽을 봄
- 끈끈이 피스톤(피스톤 + 썩은 살점): 줄어들 때 앞의 블록을 끌어옴. 흑요석·기반암·상자·화로 같은 블록은 밀 수 없음

## 날씨와 낚시
- 가끔 비가 옴(설원에서는 눈, 사막은 맑음). 비가 오면 하늘이 어두워지고 빗소리가 나며, 좀비·스켈레톤이 낮에도 타지 않음
- 뇌우 때는 번개가 떨어져 번쩍이고 천둥이 침. 가까이 맞으면 피해. 뇌우 중에는 침대에서 잘 수 있고 자고 나면 맑아짐
- 거미: 밤에 나오고 벽을 타고 오름. 낮에는 먼저 공격하지 않음. 실을 떨굼
- 낚싯대(막대기 3 + 실 2, 작업대): 물에 찌를 던지고, 찌가 쑥 들어가면 1초 안에 다시 우클릭. 대부분 생선, 가끔 잡동사니나 보물(다이아몬드, 엔더 진주 등)
- 생선은 화로에서 익힘. 실 4개로 양털을 만들 수 있음

## 양조와 물약
- 유리병(유리 3 → 3개)을 물에 대고 우클릭하면 물병. 양조대(블레이즈 막대 + 조약돌 3, 작업대)를 우클릭해 물병 + 재료로 물약을 만듦
- 치유(금괴, 즉시 체력 8), 재생(가스트 눈물, 45초), 신속(레드스톤), 화염 저항(블레이즈 막대, 불·용암 피해 없음), 야간 투시(발광석), 힘(네더 석영, 공격력 +3), 도약(엔더 진주, 더 높이 점프). 지속형은 3분
- 남은 효과 시간은 화면 오른쪽 위에 표시. 마시면 빈 병이 남음

## 그 밖의 연출
- 블록을 캐거나 부술 때 조각 파티클이 튐
- 1인칭 손과 들고 있는 도구·블록이 화면 오른쪽 아래에 보이고, 캘 때 휘두르고 걸을 때 흔들림

## 조작법
| 키 | 동작 |
|---|---|
| W A S D | 이동 (한글 입력 상태에서도 동작) |
| 마우스 / 트랙패드 | 시점 회전 (마우스 잠금이 안 되면 두 손가락 스와이프) |
| 방향키 | 시점 회전 |
| Space | 점프 / 수영 / 비행 상승 |
| Shift | 달리기 / 비행 하강 |
| 좌클릭 (누르고 있기) | 블록 캐기 / 몹 공격 |
| 우클릭 · 두 손가락 클릭 · Ctrl/⌥+클릭 · R | 블록 설치 / 음식 먹기 / 작업대·화로 열기 |
| E | 인벤토리와 제작 |
| 1-9, Tab, [ ] | 아이템 고르기 (마우스 잠금 중에는 휠도 가능) |
| Q | 들고 있는 아이템 하나 버리기 (Ctrl+Q: 한 묶음) |
| F | 비행 (크리에이티브) |
| 휠클릭 | 보고 있는 블록 선택 |
| F3 | 디버그 정보 |
| Esc | 일시정지 |

### 아이패드
- 하드웨어 키보드의 WASD가 한글 입력 상태(ㅈㅁㄴㅇ)에서도 동작합니다.
- 트랙패드: 화면을 클릭하면 마우스 잠금을 시도합니다. 잠금이 안 되는 환경(Claude 앱 등)에서는 커서를 조이스틱처럼 씁니다. 커서를 가운데에서 멀리 둘수록 그쪽으로 빠르게 돌고, 가운데 원 안에 두면 멈춥니다. 커서가 게임 화면 밖으로 나가도 계속 돕니다. 두 손가락 스와이프로도 돌릴 수 있습니다. 메뉴에서 방식(조이스틱 / 커서 이동 / 스와이프만), 감도, 스와이프 방향을 바꿀 수 있습니다.
- 우클릭: 두 손가락 클릭, Ctrl이나 ⌥를 누른 채 클릭, 또는 R 키.
- 화면을 손가락으로 터치하면 터치 조작 버튼이 나타나고, 키보드를 누르면 사라집니다.
