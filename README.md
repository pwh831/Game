# BlockCraft

브라우저에서 바로 실행되는 마인크래프트 스타일 복셀 게임입니다. 설치할 것 없이 `index.html`을 브라우저로 열면 됩니다.
(Three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 기능
- 무한 지형 자동 생성: 평지, 언덕, 설산, 바다, 모래사장, 동굴, 나무
- 1인칭 이동, 점프, 달리기, 수영, 비행 모드
- 블록 부수기/설치, 블록 9종 핫바, 휠클릭으로 블록 선택
- 앰비언트 오클루전 음영, 낮/밤 순환, 해와 달, 구름, 수중 효과
- 월드 변경 사항과 플레이어 위치 자동 저장(localStorage)
- 모바일 터치 조작(가상 스틱과 버튼)

## 조작법
| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| 마우스 | 시점 회전 |
| Space | 점프 / 수영 / 비행 상승 |
| Shift | 달리기 / 비행 하강 |
| F | 비행 모드 켜기/끄기 |
| 좌클릭 / 우클릭 | 블록 부수기 / 설치 |
| 휠클릭 | 보고 있는 블록 선택 |
| 1-9, 마우스 휠 | 블록 고르기 |
| F3 | 디버그 정보 |
| Esc | 일시정지 |

"새 월드" 버튼을 누르면 새 시드로 월드를 다시 만듭니다(기존 저장 데이터는 지워집니다).
